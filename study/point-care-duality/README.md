#Learning and composing  Attention mechanisms

- Transformers achieve parallel execution while preserving sequential information through positional encoding.
The sequential independence of a pure word embedding is a problem if you want to understand a text that's made from multiple words - this is why we add into it the positional encoding, token by token. That's actually the contribution of the transformer model - parallel execution WITHOUT losing the sequential signal.
